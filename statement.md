# Project Statement

## Problem Statement
This project develops a command-line ATM Banking and Transaction Simulation System using Python. It models account management, card authentication, cash transactions, fund transfers, transaction history and basic security controls without connecting to a real banking network.

## Scope
The system supports multiple registered users, automatic card/account/PIN generation, PIN authentication, withdrawal, Fast Cash, deposit, balance enquiry, fund transfer, transaction history, PIN management, card blocking/unblocking and JSON persistence.

## Target Users
- Students learning Python
- Course evaluators
- Users demonstrating an ATM workflow from a terminal

## High-Level Features
- Multiple users and cards
- Account and card generation
- PIN generation and authentication
- Failed-PIN card blocking
- Card-specific daily limits
- Withdrawal and Fast Cash
- Deposit and transfer
- Statements and receipts
- Persistent storage
- Validation and testing
